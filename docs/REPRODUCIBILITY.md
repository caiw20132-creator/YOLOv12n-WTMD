The local assembly utility only collects and hashes files. It never imports the recovered experimental code or unpickles model/regressor objects. Before publishing a completed research release, use the recovered documented commands to verify checkpoint loading and reproduce the associated tables. Record the exact command, implementation/version, dataset membership, reproduced values and comparison tolerances. A new implementation inferred from the Methods is not automatically the historical implementation.

If a large cache can be regenerated from public inputs with the supplied implementation, provide those inputs and the actual regeneration command rather than uploading unnecessary duplicates. Retain original notices and distinguish source-data access from code access.
