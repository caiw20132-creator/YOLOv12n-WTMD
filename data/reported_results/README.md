# Reported results

These files transcribe aggregate values reported in the supplied manuscript and appendix dated 2026-11-03. Every row identifies its source file, table label, and source line span. They are not original per-image predictions, training logs, bootstrap resamples, or independent experimental reproduction.

`tables_original_cells.json` preserves raw TeX and plain cells for all 9 main and 24 appendix tables. `data_dictionary.json` documents CSV columns, endpoints and units. AP values use 0–1; effect and confidence-interval columns ending `_pp` use percentage points. Displayed precision is retained. Differences computed before source rounding may differ from subtraction of displayed values. Separate native overall AP, group-specific scale AP and fixed-matching ranking AP must not be pooled or added.

Study-specific original inputs and executable historical code must be supplied separately to reproduce network inference and fitted/post-processing results. The CSV files support transparent reporting and arithmetic checks, not a claim that original experiments were rerun.
