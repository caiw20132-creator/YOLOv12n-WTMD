# YOLOv12n-WTMD 实验档案

最终正文依据为作者提交的 main(1).pdf。正文 13 张表转录为具名 CSV。第 31 页单独列出 S1，配套 S1 数据由工作区对应版本核对。文件名和 SHA-256 见 metadata/manuscript_sources.json。

## 目录和用途

| 目录 | 内容 |
|---|---|
| data | 当前 5,744 图成员清单、数据源版本、外部队列统计与类别映射 |
| data/reported_results | 正文与 S1 的表格转录，按 table_index.json 查表号、页码和来源 |
| evidence | 572 图主评价原始控制台记录 |
| project | 模型配置、几何记录、归档脚本及四份与 S1 摘要一致的权重 |
| configs | 正文及配套 S1 的协议转录和运行环境记录 |
| metadata | 权重身份、版本来源、按实验查找文件的索引 |
| audit | 每个原包文件的去向、451/519 图模型归属差异及历史名单核对 |

## 实验范围

- **主评价**。当前划分为 4,021／1,151／572 图。572 图原始控制台记录可核对正文主指标的四位小数。原记录显示权重路径，主权重文件摘要和训练成员关系另见审计。
- **几何和层级对照**。几何统计限当前训练与验证集。H234 配置和相关验证脚本为独立对照，权重或原始预测缓存另需取得。
- **池化续训与单独完整配置对照**。保留两条续训的原始参数、训练记录和两份续训权重。另两份权重对应 S1 的独立完整配置对照及模型运算量记录。不同记录各按原实验角色使用。
- **外部评价**。451／519 图的原始日志与论文模型归属相反，冲突的运行输出已从本包移出。审计 CSV 保留论文值、原包值及关联摘要。901 图原生指标和固定匹配重评分的稿件表值按各自口径保留。
- **运行前提**。原脚本使用历史目录及本地修改版 Ultralytics。须准备对应版本、完整数据和实际检查点。CQR、尺度及 NMS 诊断的部分逐图输入需另行取得。

## 验证

解压后在本目录运行：

~~~bash
python tools/verify_archive.py
~~~

验证文件 SHA-256、四份权重身份、当前划分、正文表转录索引、外部归属差异、原始主评价舍入和干预表内部平衡。完整复跑需要对应原始输入和运行环境。
